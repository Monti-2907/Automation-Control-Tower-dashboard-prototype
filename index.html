What this sample demonstrates

The source workflow tags each step VA (value-added) or NVA; its own automation note names file intake, VLOOKUP enrichment, SAP extraction, and status/vendor assignment as scriptable, with the main change being that the final email moves from an individual mailbox to a shared service account. This sample automates every NVA step and keeps today's human-trigger points visible — receiving files by email, running the SAP extraction, and RCA/SPOC status calls — rather than hiding them, so each one stays a candidate for automation as the pilot matures.
